# AMS Persistent Reminder: specification (0.5)

Name under the icon: Persistent (0.5.1; so that typing "persistent" in iPhone search finds it, as search matches only the start of a word; "AMS" or "reminder" no longer find it). Bundle id: com.schabbauer.AMSPersistentReminder. iPhone only, portrait, iOS 17+. Positive, calm, Apple look; Apple's standard text sizes; compact rows.

## 1. Idea
A reminder keeps nudging every N minutes from its due time until it is ticked off. All rules live in `Core/Sources/ReminderCore/Reminders.swift` and are tested with `swift test --package-path Core`.

## 2. Data
- Reminder: id, title, due (next time it is for), repeats (never / daily / weekly / monthly / onDays / hours / days), nudgeMinutes (default 5), shortcut (optional text: the exact name of one Apple Shortcut; empty or missing = none; stored trimmed), tickWhenRun (true/false, default true; read as true when missing), colour (red, orange, yellow, green, teal, blue, purple, pink or none; default none; an unknown colour reads as none), pausedUntil (0.4; optional time; missing = not paused; a time in the past counts as not paused), created. Added in 0.5, all optional and read tolerantly: note (text), action {kind: call or link, value, label}, sound (iphone, chime, bell, marimba, pop, rise, knock; default iphone), louder (true/false, default true), stopAt (minutes after midnight; missing = none), every (hours or days count, for the Hours and Days repeats), weekdays (list, 1 = Sunday ... 7 = Saturday, for On days), afterDone (true/false, default false), place {name, latitude, longitude, radius (100/200/500 m), onArrive (true = arrive, false = leave)}, pausedFrom (time; start of a weekend pause).
- Done entry: id, the reminder as it was when ticked, doneAt, nudges, skipped (0.5; true = skipped, not done; missing = false).
- List: format number (1), reminders, done entries.
- All-nudges pause (0.4): kept in the app's settings on the iPhone (not in the reminders file): mode On / Off / Until (a time); 0.5 adds Weekend (Until with the weekend's end). Other 0.5 settings, also in the app's settings: louder switch (default on), quiet hours (on/off, start and end minutes after midnight, default 22:00-07:00 when switched on), the three later buttons (default 10 min, 1 hour, This evening; chosen from 5 min, 10 min, 15 min, 30 min, 1 hour, 2 hours, This evening), iCloud copy switch and the time it was last saved. The 0.3.4 switch stored as off reads as Off; on reads as On. It is not part of the safety copy.
- Tolerant reading: a missing or unreadable field gets a sensible value (new id, empty title, due now, Never, 5 minutes, no shortcut, tick when run on, now) instead of losing the reminder; a missing list reads as empty; a later version's extra fields are ignored.
- Stored as one data file on the iPhone. A safety copy is kept each day; the last 7 days are kept. 0.5 also keeps a copy in iCloud (section 7).

## 3. Rules
- Waiting: a reminder is waiting when due <= now.
- Interval: nudgeMinutes, never less than 1 minute. Choices: 1, 5, 10, 15, 30, 60.
- Nudge counting: the first nudge comes at the due time. Nudges so far = floor((now - due) / interval) + 1 when due <= now, otherwise 0. The next nudge is due + (nudges so far) x interval; before the due time it is the due time.
- Tick: the entry goes to the top of Done with doneAt = now and nudges = nudges so far. A reminder with Never leaves the list. A repeating one moves its due to the next occurrence strictly after now, counted from its own due time: daily = +n days, weekly = +n weeks, monthly = +n months (a 31st stays on the last day of short months and returns to the 31st). Its nudge count then starts again.
- Done text: 1 nudge or fewer = "On time"; otherwise "After N nudges".
- Bring back: the reminder returns with the due time it had when ticked (a repeating one that still exists gets that earlier due back; otherwise it is added again) and the Done entry goes.
- Snooze (In 10 minutes, In 1 hour, This evening, Tomorrow morning): sets due to the new time; nudges count again from there.
- Shortcut: a reminder with a non-empty shortcut name can run it from the nudge or from its row.
- Tick when run: with tickWhenRun on (the default, also for reminders saved before 0.3), running the shortcut from the row or from the nudge's Run button ticks the reminder off at the same moment by the normal Tick rule (Done entry, a repeating one moves on, nudges stop; Bring back undoes it). With it off, running never ticks the reminder off, never moves its due time and never changes its nudge count; it keeps nudging until ticked off (as in 0.2). "Try it" on the edit screen never ticks.
- Shortcut list: the names of the user's shortcuts, kept in the app's settings on the iPhone, sorted A-Z, without the helper "AMS Persistent Reminder Helper" and the old name "AMS Reminder List". Empty until loaded.
- Colour: only shown when the reminder repeats. Switching a coloured reminder to Never keeps the colour in the data but does not show it; it shows again if the reminder repeats again.
- Pause (0.4): a reminder is paused while pausedUntil is set and later than now. All nudges are paused while the all-nudges mode is Off, or is Until a time later than now. Pause never changes due, repeats, the nudge count or Done; it only stops nudges from being planned.
- Pause times: "Tomorrow" = tomorrow 08:00. "Pick a day" = 08:00 on the chosen day (a day from tomorrow on). Nudges resume at that moment by themselves. "Nudge again now" clears pausedUntil. Planning (section 6) plans a paused reminder's nudges only from the pause's end: the first nudge is at the later of its due time and the pause's end, then every N minutes. A reminder that is waiting when its pause ends starts nudging at the pause's end (count from there). Ticking a paused reminder works as always.
- Weekend pause (0.5): sets pausedFrom to Saturday 00:00 (or now, if it is already Saturday or Sunday) and pausedUntil to the next Monday 08:00. No nudges are planned in between. Row: "Paused for the weekend".
- Louder (0.5, switch default on, per reminder `louder` and the Settings switch): from the 4th nudge the interval is halved (never under 1 minute) and the stronger sound is used.
- Sound (0.5): iPhone (default), Chime, Bell, Marimba, Pop, Rise, Knock; tapping one in the picker plays it. Used by every nudge of that reminder.
- Quiet hours (0.5): no nudges are planned between start and end (may cross midnight). A reminder still waiting gets its next nudge at the end of the quiet hours.
- Stop nudging at (0.5): `stopAt` minutes after midnight. Nudges after that time on the reminder's due day are not planned. It stays on the list; row: "Stopped nudging at 18:00".
- Later buttons (0.5): three of the seven choices; each moves due to now + that time (This evening = 19:00, or Tomorrow morning 08:00 late in the day).
- Repeat (0.5): Never, Daily, Weekly, Monthly, On days (weekdays set; chips Weekdays = Mon-Fri, Weekend = Sat+Sun; next = the next chosen day after now at the same time), Hours (every 1-12 hours), Days (every 1-30 days). afterDone: the next time is counted from doneAt (+ the interval) instead of from the old due time; row words such as "3 days after done".
- Skip (0.5): for a repeating reminder, moves due to its next time by the repeat rule without a nudge; adds a Done entry with skipped = true, shown as "Skipped"; it counts neither as done nor as late and does not count in the green ring.
- Quick move (0.5): swipe Later = In 15 minutes, In 1 hour, Tonight 19:00, Tomorrow 08:00; sets due like a snooze.
- Place (0.5): `place` {name, latitude, longitude, radius 100/200/500, onArrive}. The reminder starts nudging (its due becomes now) when the iPhone reports entering (onArrive) or leaving the circle, also while the app is closed (region monitoring, location "Always"). Such reminders are in the group "At a place"; row: "When you arrive at Home" / "When you leave Home".
- Note (0.5): free text shown under the title and in the nudge.
- Action (0.5): kind call (a contact's number or a typed number; opens `tel:`) or link (a web address; opens it); label = the contact's name or the address. Press and hold the row, or the nudge's first button ("Call Anna" / "Open link"). A reminder with a shortcut keeps "Run: ..." first.
- Undo after ticking (0.5): a bar "Ticked off: <title>" with "Undo" for 5 seconds; Undo = Bring back.
- Speak (0.5): see section 5, Reminders. Time words: at 3 / at 3 pm / at 15:30 / half past 4 (next such time; 24 h if no am/pm and already past: the next day), in N minutes, in N hours, tomorrow (same time, or 08:00 with no time), tonight / this evening = 19:00, tomorrow morning = 08:00, weekday names (the next such day). The time words are removed from the title. Nothing heard: "I didn't catch that".
- Forgetting: Done entries older than 30 days (counted from the start of today) are dropped.

## 4. Quick times
- In 10 min: now + 10 minutes. In 1 hour: now + 1 hour.
- This evening: today 19:00. After 19:00 the button reads "Tomorrow evening" and means tomorrow 19:00.
- Tomorrow 8:00: tomorrow at 08:00.
- On a nudge: "This evening" the same way; late in the day (after 19:00) it reads "Tomorrow morning" and means 08:00 the next day.
- By hand: day (Today / Tomorrow / Pick a day with a calendar), hour from a grid 06:00-21:00, minutes :00 :15 :30 :45.

## 6. The nudge
- A message at the due time, also on the lock screen, then every N minutes: "Since 08:00 · 3rd nudge".
- Press and hold for buttons: [Run: <shortcut name> (only when the reminder has a shortcut; always first)], [Call <name> / Open link (0.5, when the reminder has one)], Done, and (0.5) the three later buttons chosen in Settings (default In 10 minutes, In 1 hour, This evening; late in the day This evening reads Tomorrow morning, 08:00). The note is shown in the message. Sound = the reminder's sound; louder from the 4th nudge. Done ticks it off without opening the app (including moving on a repeating one).
- Planning: the iPhone holds about 64 planned messages, so the app plans up to 60 nudges ahead, earliest first across all reminders. It tops them up every time it opens or the list changes. A reminder left for many hours may go quiet until the app is opened.
- Permission: if the iPhone does not allow nudges, the Nudges row in Settings offers a "Turn on" button to the iPhone's settings. Pause (0.4): while all nudges are paused, none are planned; for a paused reminder, nudges are planned only from the pause's end. When the pause ends the nudges start again by themselves at 08:00 of the chosen day (the app plans them ahead, so no opening is needed).

### 6a. Running a shortcut
- The name must match the shortcut's name in the Shortcuts app exactly (same capitals and spaces), e.g. "Call Andreas Bjurling". If it does not, the Shortcuts app says it cannot find it.
- Handover: the app opens the link `shortcuts://run-shortcut?name=<percent-encoded name>`. The Shortcuts app runs it; no result is waited for.
- From the nudge: the Run action has the option "open the app" (foreground), so pressing it opens the app for a moment, which then makes the handover. With tickWhenRun on, the reminder is ticked off at the same moment (the handover still happens); with it off it stays on the list and keeps nudging until ticked off.
- Notification categories: `nudge` (Done, In 10 minutes, In 1 hour, This evening) and `nudge-late` (the same with Tomorrow morning) for reminders without a shortcut. A reminder with a shortcut gets its own pair, `nudge-sc-<uuid>` and `nudge-late-sc-<uuid>` (uuid = the reminder id), whose first action is "Run: <name>" (opens the app); the other four actions are as before. The categories are registered together before nudges are planned and are rebuilt whenever the list changes; each planned nudge carries the category of its reminder.
- From the row: a long press of 0.5 s on a row with a shortcut gives a short haptic buzz and makes the same handover and, with tickWhenRun on, ticks the reminder off with the happy buzz. A tap still opens the reminder; swipes are unchanged.
- From the edit screen: "Try it" makes the same handover and never ticks.

### 6b. Your shortcuts (the list page)
- Opened by the Pick button on the edit screen (`pick-shortcut`) or the Settings row (`settings-shortcuts`). A list (`shortcut-picker`) of the stored names with a search field at the top; each row `shortcut-option-<name>`; tapping one puts the name into the Shortcut field and closes the page. A name can still be typed by hand.
- An iPhone app cannot read the user's shortcuts, so a helper shortcut "AMS Persistent Reminder Helper" does it. First time (empty list) the page says so and shows two steps: "1. Add the helper" (`add-helper`) and "2. Load my shortcuts" (`load-shortcuts`). Later "Load again" (bottom of the page, and in Settings › Shortcuts › Your shortcuts) runs the helper again and comes back with the new list.
- Add the helper (`add-helper`): a share sheet with the bundled, signed file `AMS Persistent Reminder Helper.shortcut`; the user chooses Shortcuts, then "Add Shortcut". (0.3 opened `shortcuts://import-shortcut?url=…`; iOS 27 answers "The shortcut URL provided was invalid", so 0.3.1 dropped it, and the separate `share-helper` line with it.) The helper also syncs from the Mac's Shortcuts through iCloud.
- Nudge buttons are answered with the completion-handler delegate methods on the main thread (0.3.1). The async forms crashed: iOS finished them on a background thread and UIKit aborted (TestFlight crash reports, 0.1 and 0.3).
- Load: the app runs the helper by `shortcuts://run-shortcut?name=AMS%20Persistent%20Reminder%20Helper`. The Shortcuts app flashes up, collects the names and opens the link back `amsreminder://shortcuts?names=<one name per line, encoded>`. The app stores them sorted A-Z, without "AMS Persistent Reminder Helper" and "AMS Reminder List", and shows the list. The first time, iOS may ask whether "AMS Persistent Reminder Helper" may open AMS Reminder (Allow / Always Allow).
- The helper file `App/Resources/AMS Persistent Reminder Helper.shortcut` is built and signed by `python3 Tools/make-helper-shortcut.py`.

## 7. Keeping data
- One data file on this iPhone; one safety copy per day, the last 7 days kept; never put in a public repository.
- iCloud (0.5): a copy of the list is kept in the iCloud key-value store (switch "Keep a copy in iCloud", on by default) so it returns on a new iPhone; the time of the last save is shown. "Bring back from iCloud…" restores it after keeping the current list as a safety copy. "Save a copy…" writes a file in Files; "Bring back a copy…" reads one (safety copy first).
- Permissions (0.5): microphone and speech recognition (speak a reminder); location when-in-use and Always (start at a place); contacts (a picker only, no list is read); notifications as before.
- The shortcut name is stored with the reminder as the field `shortcut`. Lists saved by 0.1 (no such field) open fine. The colour is stored as `colour`; a missing or unknown value reads as none. The switch is stored as `tickWhenRun`; a missing field reads as true. The file format number stays 1; 0.5 adds the optional fields of section 2 (note, action, sound, louder, stopAt, every, weekdays, afterDone, place, pausedFrom; skipped on a Done entry), and a list written by 0.4 or earlier opens unchanged.
- The shortcut list is kept in the app's settings on the iPhone (not in the reminders file) and is not part of the safety copy.
